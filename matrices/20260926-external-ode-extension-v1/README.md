# External ODEBench extension v1

This held registration covers all 63 ODEBench systems through five official trajectory conditions, six external methods, two resource tracks, and ten seeds (37,800 represented records).

Arrays 33901--33906 correspond to PySR, Operon, DSR, AI-Feynman 2.0, gplearn, and TF4SR. They are held because no external ODE adapter has passed the common result contract. MySR is excluded from this external-only registration.
