This is an in-progress calibration matrix, not a formal performance result. It contains two representative tasks (Nguyen-1 and SRSD-Feynman-i.12.1), six horizontal methods, clean/5% output noise, two resource labels, and one pilot seed.

Slurm arrays: `33823` on node1 for manifest indices 0--23 and `33824` on node2 for indices 24--47. Each record preserves the manifest entry, host, node, seed, and import/data smoke status.
